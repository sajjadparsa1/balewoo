# بله‌وو | BaleWoo

پلاگین وردپرس/ووکامرس برای **خرید مستقیم از بله در سبد خرید ووکامرس** به همراه درگاه کارت‌به‌کارت با تأیید هوشمند از طریق ربات‌های بله و تلگرام.

دو روش پرداخت به‌صورت همزمان ارائه می‌شود:

| روش | شناسه درگاه | توضیح |
| --- | --- | --- |
| 💙 پرداخت آنلاین با بله | `balewoo_bale` | مشتری به کیف پول بله منتقل می‌شود، پرداخت خودکار تأیید می‌گردد |
| 💳 کارت به کارت | `balewoo_card` | مشتری رسید واریز را می‌فرستد، مدیر در بله تأیید/رد می‌کند |

## امکانات

- **پرداخت آنلاین با بله** — ساخت صورتحساب (`createInvoiceLink` / `sendInvoice`)، تأیید خودکار از طریق وب‌هوک `successful_payment` و `pre_checkout_query`.
- **کارت‌به‌کارت** — نمایش کارت‌ها در تسویه حساب، آپلود رسید در سایت یا ارسال عکس در ربات، تأیید/رد با دکمه‌های اینلاین.
- **ربات بله + تلگرام** — وب‌هوک امن با secret، اتصال حساب کاربر با `/start` (دیپ‌لینک)، دستورات مدیر (`/report`، `/pending`).
- **اعلان‌ها** — بله، تلگرام، سفیر (با شماره تلفن) و پیامک (ملی پیامک) با اولویت‌بندی کانال‌ها.
- **Undo** — بازگشت از آخرین عملیات تا ۳۰ ثانیه.
- **داشبورد** — آمار لحظه‌ای، نمودار فروش ۷ روز اخیر، نمودار وضعیت سفارشات، آخرین تراکنش‌ها و شبیه‌ساز سناریو.
- **تراکنش‌ها** — فیلتر وضعیت/پلتفرم/تاریخ، جستجو، عملیات دسته‌ای، خروجی CSV.
- **ارسال گروهی** — پیش‌نمایش زنده، ارسال تست، تاریخچه.
- **گزارش خودکار** — روزانه/هفتگی در ساعت دلخواه به بله یا تلگرام.
- **لاگ سیستم** و **ابزارهای عیب‌یابی** — تست اتصال، تست ارسال پیام، شبیه‌ساز وب‌هوک و دیباگ وضعیت تنظیمات.
- **ظاهر** — ۷ تم رنگی و حالت تاریک.

## نیازمندی‌ها

- PHP 7.4 یا بالاتر
- وردپرس 6.0+
- ووکامرس 8.0+
- افزونه cURL و OpenSSL فعال

## نصب

1. پوشه را در `wp-content/plugins/balewoo` قرار دهید (یا همین ریپو را کلون کنید) و افزونه را فعال کنید.
2. پیشخوان ← **بله‌وو ← تنظیمات ← عمومی**: توکن ربات بله را وارد کنید و وب‌هوک را ثبت کنید.
3. تب **پرداخت**: برای پرداخت آنلاین، Provider Token را وارد کنید؛ برای کارت‌به‌کارت کارت‌های بانکی را ثبت کنید.
4. ووکامرس ← پیکربندی ← پرداخت‌ها: روش‌های «بله‌وو» را فعال کنید.

## وب‌هوک

```
https://your-site.com/wp-json/balewoo/v1/webhook/bale/<secret>
https://your-site.com/?balewoo_webhook=bale&secret=<secret>   (فallback)
```

## هوک‌های توسعه

```php
add_filter( 'balewoo_payment_amount', function ( $amount, $order ) { return $amount; }, 10, 2 );
add_filter( 'balewoo_bale_api_base', function () { return 'https://tapi.bale.ai'; } );
add_filter( 'balewoo_render_template', function ( $text, $key, $order ) { return $text; }, 10, 3 );
add_filter( 'balewoo_report_text', function ( $text, $stats, $days ) { return $text; }, 10, 3 );
add_filter( 'balewoo_undo_window', function () { return 30; } );
```

## ساختار پوشه‌ها

```

admin/views|css|js              پنل مدیریت
public/views|css|js|images      صفحه پرداخت، بلوک کارت‌به‌کارت و دارایی‌ها
languages/                      ترجمه‌ها
uninstall.php                   پاک‌سازی هنگام حذف
```
