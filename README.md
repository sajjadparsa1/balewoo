# بالی‌وو شاپ — اسکریپت فروشگاه اینترنتی چند فروشنده

یک پلتفرم کامل فروشگاهی فارسی (RTL) با سه پنل **مدیریت**، **فروشنده** و **کاربر**، به‌همراه storefront عمومی،
بسته نصب خودکار، داده نمونه و مجموعه آزمون. همه کد از صفر نوشته شده و به هیچ اسکریپت یا قالب تجاری وابسته نیست.

پشته فنی: **Node.js 18+ / Express 4 / EJS / SQLite (better-sqlite3)** — بدون نیاز به PHP، Composer یا سرویس پایگاه داده خارجی.

---

## راه‌اندازی سریع

```bash
npm install          # نصب وابستگی‌ها
npm run assets       # ساخت تصاویر پایه (لوگو، فاوآیکون، آیکون دسته‌بندی‌ها)
npm run seed         # ساخت پایگاه داده + داده نمونه
npm start            # اجرا روی http://localhost:3000
```

یا نصب از راه مرورگر: سرور را اجرا کنید و به `/install` بروید — بسته نصب ۴ مرحله‌ای
(پیش‌نیازها ← اطلاعات فروشگاه ← حساب مدیر ← داده نمونه) فروشگاه را راه‌اندازی می‌کند و در پایان، مسیر نصب قفل می‌شود.

### حساب‌های نمونه

| نقش | شماره موبایل | گذرواژه | مسیر ورود |
| --- | --- | --- | --- |
| مدیر کل | `09999999999` | `12345678` | `/login` → `/admin/dashboard` |
| فروشنده | `09121000001` | `12345678` | `/login` → `/seller/dashboard` |
| مشتری | `09122000001` | `12345678` | `/login` → `/user/dashboard` |

ورود با **کد یکبار مصرف پیامکی** هم فعال است؛ در حالت `SMS_DRIVER=mock` کد در فلش پیام همان صفحه نمایش داده می‌شود.

پرداخت‌ها در حالت پیش‌فرض **sandbox** هستند: پس از ثبت سفارش، صفحه شبیه‌ساز درگاه باز می‌شود و با یک کلیک
پرداخت موفق/ناموفق قابل آزمایش است.

### دستورهای npm

| دستور | کار |
| --- | --- |
| `npm start` | اجرای سرور |
| `npm run dev` | اجرا با بارگذاری مجدد خودکار (`node --watch`) |
| `npm run seed` | ساخت داده نمونه روی پایگاه داده موجود |
| `npm run reset` | خالی کردن همه جداول و ساخت دوباره داده نمونه |
| `npm run assets` | ساخت/بازسازی تصاویر SVG پایه |
| `npm test` | آزمون دود: پیمایش ۱۳۳ مسیر GET با سه نشست کاربری + بررسی نشتی `undefined`/`NaN` در HTML |
| `npm run test:e2e` | آزمون سرتاسری: خرید کامل، کیف پول، محصول فروشنده، تیکت، عملیات مدیریتی (۴۴ بررسی) |
| `npm run test:links` | بررسی انطباق ۴۳۰ پیوند قالب‌ها با مسیرهای ثبت‌شده |

پیکربندی از راه `.env` انجام می‌شود (نمونه: `.env.example`) — پورت، کلید نشست، سرویس پیامک،
حالت پرداخت، کلید نقشه و حساب‌های نمونه.

## قابلیت‌ها

### فروشگاه (storefront)
- صفحه نخست **قالب‌بندی‌شده با بخش‌ساز** (اسلایدر، استوری، خدمات، دسته‌بندی‌ها، فهرست محصول، بنر، برندها، فروشگاه‌های برتر، مجله) و چند قالب قابل انتخاب
- آرشیو محصول با فیلتر دسته/برند/قیمت/موجودی/رنگ، مرتب‌سازی (جدیدترین، پرفروش، ارزان‌ترین، گران‌ترین، بیشترین تخفیف، محبوب) و صفحه‌بندی
- صفحه محصول کامل: گالری، متغیرها (رنگ/گارانتی/…)، **ویژگی‌های اختیاری پولی**، مشخصات کلیدی، جدول **تخفیف پلکانی**،
  امتیاز و دیدگاه‌ها، پرسش و پاسخ، نمودار **تاریخچه قیمت**، امتیاز باشگاه مشتریان، محصولات مرتبط و دیده‌شده‌های اخیر
- حالت‌های فروش: عادی، **استعلامی**، ناموجود با «اعلام موجودی» و «اعلام تخفیف»
- سبد خرید مهمان/کاربر، کد تخفیف، پرداخت با **کیف پول**، **پرداخت در محل**، **کارت‌به‌کارت** و درگاه آنلاین
- **پرداخت قسطی** (نمایش مبلغ هر قسط)، مقایسه محصولات، علاقه‌مندی‌ها، جستجوی زنده و پیشنهاد عبارت‌های پرجستجو
- مجله (مقاله/ویدیو/پادکست) با دسته، برچسب، دیدگاه و محصولات متصل به مطلب
- صفحات اطلاعاتی، فرم‌ساز تماس/درخواست، پرسش‌های متداول، برندها، فروشگاه فروشنده، نقشه مراکز تحویل حضوری
- **همکاری در فروش سه‌سطحی** با لینک اختصاصی `?ref=CODE` و گزارش پورسانت
- استوری‌های فروشگاه، خبرنامه، سئو کامل (متا، Open Graph، Schema.org، sitemap.xml، robots.txt) و حالت تاریک/روشن

### پنل کاربر (`/user`)
داشبورد، سفارش‌ها و جزئیات/فاکتور/لغو، مرجوعی، پیش‌فاکتور و پرداخت آن، کیف پول و تراکنش‌ها، شارژ کیف پول،
باشگاه مشتریان (سطح، امتیاز، گردش امتیاز)، نشانی‌ها، حساب‌های بانکی و درخواست برداشت، علاقه‌مندی‌ها، مقایسه،
دیدگاه‌ها و پرسش‌ها، اعلان موجودی/تخفیف، اعلان‌ها، تیکت پشتیبانی، همکاری در فروش، ویرایش پروفایل و گذرواژه، نشست‌های فعال.

### پنل فروشنده (`/seller`)
داشبورد با نمودار فروش، محصولات (ساخت/ویرایش/متغیر/ویژگی/تصویر/سئو)، **قیمت‌گذاری رقبا**، موجودی و انبارها،
گردش انبار، سفارش‌ها و تغییر وضعیت آیتم‌ها، چاپ برچسب ارسال، تسویه‌ها و برداشت، حساب بانکی، دیدگاه‌ها و پرسش‌های محصولات،
مقاله‌های فروشنده، تنظیمات فروشگاه (لوگو، بنر، شرح، کمیسیون)، تیکت و آمار بازدید.

### پنل مدیریت (`/admin`)
- **داشبورد**: کارت‌های آماری، نمودار فروش/بازدید، قیف تبدیل، فروشنده‌های برتر، کم‌موجودی‌ها، فعالیت‌های اخیر
- **محصولات**: CRUD کامل، تأیید/رد محصول فروشنده، ویرایش گروهی، قیمت‌گذاری، موجودی، سوابق قیمت، زباله‌دان و بازیابی
- **دسته‌بندی‌ها** چندسطحی با آیکون/تصویر و **برندها**، **ویژگی‌ها (attribute groups)** و **متغیرها**
- **سفارش‌ها**: جزئیات، تاریخچه وضعیت، تغییر وضعیت، کد رهگیری، فاکتور، برچسب ارسال، خروجی CSV، مرجوعی‌ها، سبدهای رهاشده
- **مالی**: تراکنش‌ها، درگاه‌ها، **تسویه فروشندگان (روزشمار)**، **برداشت‌ها**، پیش‌فاکتورها، کدهای تخفیف، کمیسیون‌ها، گزارش درآمد
- **مردم**: کاربران، نقش‌ها و **سطح دسترسی (ACL)**، فروشنده‌ها و تأیید مدارک، نشست‌ها، گزارش فعالیت‌ها، مسدودسازی
- **محتوا**: مجله، دسته‌های مجله، صفحات، فرم‌ساز و ارسال‌ها، منوها، بنرها، استوری‌ها، دیدگاه‌ها، پرسش‌ها، FAQ، خبرنامه، قالب‌های صفحه‌ساز
- **تنظیمات**: عمومی، سئو، **درگاه‌های پرداخت (۲۱ درگاه)**، **سرویس‌های پیامک (۶ سرویس)**، نرخ ارز، نقشه، ویجت‌ها، باشگاه مشتریان، ارسال و مالیات
- **سیستم**: کتابخانه مدیا، تیکت‌ها، اعلان‌ها، گزارش‌ها و آمار، پشتیبان‌گیری/بازیابی، بهینه‌سازی پایگاه داده، پاکسازی کش، بررسی به‌روزرسانی

## ساختار پروژه

```
server.js                  نقطه ورود
scripts/gen-assets.js      ساخت تصاویر SVG پایه
src/
  app.js                   ساخت برنامه Express، میان‌افزارها، متغیرهای سراسری قالب
  config.js                پیکربندی از .env
  db/
    schema.sql             ۷۲ جدول + ایندکس‌ها
    index.js               اتصال، migration، لایه داده، کش تنظیمات
    seed.js                داده نمونه (کاربر، فروشنده، محصول، سفارش، مجله، آمار)
  core/                    jalali · utils · cache · seo · activity · acl · notify · auth · media · catalog · barcode
  services/                sms · payment · shipping
  modules/                 cart · orders · routes/…
  views/                   ۱۳۴ قالب EJS (storefront ۱۴ · user ۲۴ · seller ۱۴ · admin ۵۰ · auth/payment/errors/install)
  public/                  css/app.css · js/app.js · fonts · img
tests/                     smoke.js · e2e.js · links.js
docs/SCRAPE_REPORT.md      فهرست قابلیت‌های مرجع (۷۸ مورد) که این پروژه پیاده‌سازی کرده است
```

### لایه داده
SQLite با `better-sqlite3` به‌صورت همزمان (synchronous) — بدون سرور پایگاه داده. ساختار در `src/db/schema.sql`
تعریف شده و در هر اجرا با `migrate()` ساخته/به‌روزرسانی می‌شود (ستون‌های جدید با `ALTER TABLE` افزوده می‌شوند).
فایل پایگاه داده در `data/balewoo.sqlite` و فایل‌های بارگذاری‌شده در `src/public/uploads/` ذخیره می‌شوند.

### تقویم و زبان
همه تاریخ‌ها **شمسی** هستند (`src/core/jalali.js`) و همه اعداد در قالب‌ها با `h.toPersianDigits()` فارسی نمایش داده می‌شوند.
چارت‌ها با جاوااسکریپت خالص روی `<canvas>` رسم می‌شوند (بدون کتابخانه خارجی).

### دسترسی‌ها
`src/core/acl.js` نقش‌ها و مجوزها را مدیریت می‌کند؛ در قالب‌ها با `can('orders.view')` و در مسیرها با
`auth.requirePermission('…')` استفاده می‌شود. نقش «مدیر کل» به همه مجوزها دسترسی دارد و نقش‌های سفارشی
از پنل مدیریت قابل ساختن هستند.

## استقرار (Production)

```bash
cp .env.example .env       # APP_KEY و آدرس سایت را تنظیم کنید
npm ci --omit=dev
npm run assets
npm start                  # یا با pm2 / systemd
```

نکته‌ها:
- `APP_KEY` را به یک رشته بلند تصادفی تغییر دهید و `NODE_ENV=production` بگذارید.
- در حالت production حتماً پشت HTTPS باشید (`TRUST_PROXY=true` برای پروکسی معکوس).
- کلید درگاه‌های پرداخت و سرویس پیامک را از پنل مدیریت وارد و حالت sandbox را خاموش کنید.
- از `/admin/system/backup` به‌صورت دوره‌ای پشتیبان بگیرید (فایل‌ها در `data/backups/`).

## وضعیت آزمون‌ها

- **آزمون دود**: ۱۳۳ مسیر GET با نشست‌های مدیر/فروشنده/مشتری/مهمان — بدون خطای ۵۰۰ و بدون نشتی `undefined`/`NaN`/`[object Object]`
- **آزمون سرتاسری**: ۴۴ بررسی روی جریان خرید (سبد ← کد تخفیف ← پرداخت آزمایشی ← کسر موجودی ← امتیاز باشگاه ← تسویه فروشنده)،
  شارژ کیف پول، ساخت و تأیید محصول فروشنده، تیکت پشتیبانی و صفحات مدیریتی
- **آزمون پیوندها**: ۴۳۰ پیوند قالب‌ها با ۱۴۳ مسیر GET و ۱۷۲ مسیر POST مطابقت دارند
- **بسته نصب**: جریان ۴ مرحله‌ای نصب روی پایگاه داده خالی به‌صورت کامل آزمایش شده است
