### مسیرهای پنل‌ها (از لندینگ استخراج شد)
```
ورود:              /login            (شماره نمونه: 09999999999)
پنل مدیریت:        /admin/dashboard
پنل فروشندگان:     /seller/dashboard
پنل کاربران:       /user/dashboard
ورود با گذرواژه:   /login?status=password
```

### ساختار هدر/ناوبری دمو
- نوار بالایی: بنرهای تبلیغاتی (gif) با لینک به راستچین
- هدر: لوگو، جستجو، آیکون سبد (با شمارنده)، منوی «دسته‌بندی‌ها» (مگا‌منو چندسطحی)،
  سوییچ حالت شب/روز (آیکون ماه)، لینک ورود
- منوی اصلی: صفحه نخست، مجله، پرسش‌های متداول، فروشنده شوید، تماس با ما، شماره تماس
- فوتر: لوگو، لینک‌ها، دسته‌بندی‌ها، نمادها
- ویجت «محصولات پربازدید هفته» و «بیشترین جستجوها» در تمام صفحات

### ساختار آرشیو محصولات
`/products?cat=<slug>` ، `/products?search=<term>` — فیلتر بر اساس دسته، برند، قیمت، عملکرد.

### ساختار صفحه محصول (آنچه در DOM دیده شد)
- کد محصول (مثلاً `p-8593125`) و «شناسه محصول»
- گالری تصاویر + تصاویر ارسالی خریداران
- اسلایدر متنی آمار: «+۴۱۰۰ نفر این کالا را مشاهده کرده‌اند»، «+۱۰۰ نفر علاقه دارند»
- برچسب‌ها: «فروش ویژه»، «محصول ویژه»، «کالای اصل»
- امتیاز ۵ ستاره + تعداد دیدگاه + تعداد پرسش + «۱۰۰٪ از کاربران پیشنهاد کرده‌اند»
- انتخاب متغیر (رنگ، گارانتی)
- **ویژگی‌های اضافی اختیاری با قیمت** (بند سیلیکونی ۴۵۰٬۰۰۰ / بسته‌بندی ویژه ۱۲۰٬۰۰۰ / گلس شیشه رایگان)
- خصوصیات برجسته (کلید: مقدار)
- باکس فروشنده: لوگو، نام، «فروشگاه اصلی»، عملکرد (عالی)، روش ارسال، آماده ارسال
- قیمت + قیمت خط‌خورده + درصد تخفیف + شمارش معکوس فروش ویژه
- نمایش اقساط: «۴ قسط بدون کارمزد، ماهانه ۱٬۶۳۷٬۵۰۰ تومان» (اسنپ‌پی و ترب‌پی)
- امتیاز باشگاه مشتریان (۶۵۵ امتیاز)
- **جدول تخفیف پلکانی** (۵ عدد → ۶٬۰۰۰٬۰۰۰ / ۱۰ عدد → ۵٬۸۰۰٬۰۰۰)
- لینک همکاری در فروش
- محصولات مرتبط، نمودار تغییرات قیمت، نظرات (نقاط قوت/ضعف، پیشنهاد خرید)، پرسش و پاسخ
- حالت «استعلام موجودی» به‌جای قیمت + «ناموجود»

## ۶) نتیجه‌گیری برای پیاده‌سازی ما

همه موارد بالا در پروژه **Balewoo Shop** (این ریپازیتوری) از صفر و مستقل پیاده‌سازی شده‌اند.
هیچ کد، تصویر یا متن کپی‌رایت‌داری از ویماشاپ استفاده نشده؛ فقط **لیست قابلیت‌ها و ساختار UX**
به‌عنوان مشخصات محصول الهام گرفته شده و پیاده‌سازی کاملاً اصلی است.

تفاوت‌های کلیدی پیاده‌سازی ما:
- استک: **Node.js + Express + SQLite + EJS (SSR) + Vanilla JS (ناوبری SPA-مانند)** — بدون نیاز به PHP/ionCube
- نصب با `npm install && npm start` روی هر هاست Node
- درگاه‌های پرداخت و پیامکی به‌صورت **درایور پلاگین‌پذیر** (حالت sandbox پیش‌فرض)
- همه پنل‌ها (مدیر/فروشنده/کاربر) با ACL واقعی
